# 优化器 API

## `CMAESOptimizer`

优化器为每个 mjlab 环境采样一组候选参数，写入物理模型，通过 `tell()` 累积角度误差，通过 `evolve()` 推进一代。历史和显式环境更新签名见[高级优化](advanced.md)。

构造函数接受标准 PACE 排列的有限、有序边界及正迭代数。`tell()` 只接受形状为 `[population_size, len(joint_order)]` 的有限浮点张量；非法输入不会修改优化器状态。

`update_simulator()` 在修改模型前检查模型张量及执行器延迟容量，避免校验失败后留下只应用了一部分的候选参数。

采集辅助函数与 CMA-ES 共用经过校验的模型适配器，因此惯量、阻尼、摩擦、编码器偏置、力矩延迟、重置和 `forward()` 语义保持一致。
