# PACE 执行器模型

PACE 将执行器与被动关节参数组合起来重现实际角度响应：

| 参数 | 含义 | 单位 |
| --- | --- | --- |
| `armature` | 折算到关节的附加转动惯量 | kg·m² |
| 被动 `damping` | 与速度相关的黏性阻尼，不是控制器 Kd | N·m·s/rad |
| `frictionloss` | 库仑摩擦项 | N·m |
| `encoder_bias` | 仿真角与编码器角的坐标偏差 | rad |
| `delay` | 所选关节共享的有效力矩延迟 | 仿真步数 |

位置反馈采用编码器坐标 `q_encoder = q - bias`，PD 控制使用该坐标反馈，随后计算直流电机力矩—转速饱和，最后延迟已计算的力矩。被动惯量、阻尼、摩擦通过模型参数作用于关节动力学。

mjlab 内部编码器偏置符号与 PACE 相反，兼容层负责转换。不要在外部重复减去或加上 bias；更不能把辨识 bias 直接视为已经测量确认的硬件零位。

非负 delay 截断为整数步。例如 `4.5889` 对应 4 步，在 400 Hz 下为 10 ms。它描述本模型吸收的有效延迟，不是单独测量的网络传输时间。

参数可能互相补偿。应结合独立采集、边界命中情况和重复性解释结果，见[Dobot 实验分析](../analysis/dobot_bias_comparison_20260912.md)。
