# Dobot 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 找不到 `.venv-hardware` 或 DDS 模块 | 检查 CPython 3.10、厂商 wheel 与原生 `.deb`；不要装入错误环境 |
| `doctor` 报清单缺失或哈希不符 | 取得匹配的厂商包和模型，核对 `runtime/MANIFEST.sha256` |
| 没有 `192.168.5.100` 或 URI 冲突 | 检查机器人网卡地址、路由、CycloneDDS XML 和终端环境变量 |
| `observe` 无状态 | 检查网络、机器人状态发布与 DDS 配置；重复创建 writer 不能解决读取问题 |
| 保持检查失败或采集不合格 | 查看报告中的具体原因，核对支撑、中心角、跟踪、时序和温度；不要直接放宽门限 |
| 转换提示缺少 chirp 或不合格 | 确认使用的是成功的扫频采集，而非 hold-only 或中断记录 |
| 缺少清单、增益或配置不匹配 | 恢复对应 `.pt.json`、原 NPZ 与采集配置；不要使用另一实验的配置 |
| 显存不足 | 减小 `--num_envs`，先从少量候选验证运行 |
| 低 RMSE 但姿态仍不合理 | 核对坐标、零位、bias 补偿和模型边界，独立评价几何姿态 |
